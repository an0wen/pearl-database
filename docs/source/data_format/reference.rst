Data file reference
===================

These tables describe source, EOS, and thermo metadata TOML files.
Values shown are examples, not defaults. Required means the field must be present;
type and format describe its contents. This page does not validate scientific accuracy.

The schema coverage checker reports data fields absent from these definitions.
Model-specific fields not yet defined in the schemas are reported for review.
